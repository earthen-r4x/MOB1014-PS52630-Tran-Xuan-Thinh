# Cách cài NetBeans

Truy cập link https://installers.friendsofapachenetbeans.org/ và sau đó chọn mục Windows x64 nếu dùng Windows

Say khi tải xong, mở file Apache-NetBeans-31.exe ở đường dẫn đã cài

Chọn next, sau đó Install

Tick vào "Launch Apache NetBeans" và nhấn Finish

# Cách đăng ký tài khoản Github

Truy cập https://github.com

Nhấn vào nút Sign up

Điền đầy đủ thông tin gồm Email, mật khẩu, tên người dùng, quốc gia, sau đó nhấn Continue

Lúc này, app sẽ yêu cầu mã gồm 8 kí tự. Hãy mở Gmail để xem và nhập mã, sau đó nhấn Continue.
